# UNIT-404

## Versión de Unity
**Unity 6000.3.23f1** (plantilla URP). Todos deben usar exactamente la misma versión.

## Cómo clonar
```
git clone <url-del-repo> UNIT-404
cd UNIT-404
git checkout -b integrante-N
```
Abrir la carpeta con Unity Hub usando la versión acordada.

## Reglas
- Cada quien trabaja solo en `Assets/IntegranteN` y en sus escenas.
- Cada quien trabaja en su rama `integrante-N`; nunca push directo a `main`.
- Nadie toca `ProjectSettings/TagManager.asset` (tags y capas) salvo el Integrante 1.

Ver `docs/ACUERDOS.md` para tags, capas, escenas y eventos.
